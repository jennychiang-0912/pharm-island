探索藥理，逐格征服。參考 PaGamO 領土佔領玩法的藥理學複習遊戲（單人模式）。

線上玩：https://jennychiang-0912.github.io/pharm-island/

## 地圖架構

由下到上分四層，全部使用同一套世界座標，縮放拖曳時相對位置不變：

1. **海水**：`sea-tile.jpg` 平鋪在地圖容器背景，大小與位置跟著地圖移動，拖到哪裡都不會露出空白。
2. **裝飾**：小島、礁石、浪花。依區塊（`PI.ART.chunkSize`）用固定亂數擺放，畫面拖到哪裡才產生哪裡，離太遠的區塊會移除；不會擺在領地格子上。
3. **格子**：依章節資料動態產生，也依區塊分組，只顯示畫面附近的區塊。
4. **選取外框**。

想換素材或調整數量，改 `js/data.js` 的 `PI.ART`。

## 地圖規則

- 每章一群格子：中心一格加周圍最多六格，數量由 `js/data.js` 的 `cells` 控制（目前每章 7 格）。
- 章節變多時，各章的格子群會一圈一圈往外擴展，不需要手動排位置。
- 每章的中心格一開始就是「可挑戰」；佔領一格後，相鄰的格子會變成可挑戰。
