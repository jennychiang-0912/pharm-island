# 藥理學小島

動物森友會風格的藥理學記憶遊戲。島上會冒出藥物的影子，看線索猜出是哪個藥，猜對才算鑑定成功，收進依類別分組的圖鑑。

- 線上玩：https://jennychiang-0912.github.io/pharm-island/
- 進度只存在自己的瀏覽器裡

## 資料格式

藥物資料寫在 `index.html` 最上方的 `AREAS`、`CLASSES`、`DRUGS` 三個陣列，欄位說明在檔案裡的註解。

- **區域**：通常一章一區，最多 5 區
- **類別卡**：同一類藥的共同機轉、共同重點、口訣
- **藥物卡**：辨識特徵（影子線索，必填，不可寫出藥名）、其他重點、易混淆、口訣
