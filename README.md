# PHARMA ISLAND

探索藥理，逐格征服。參考 PaGamO 領土佔領玩法的藥理學複習遊戲（單人模式）。

線上玩：https://jennychiang-0912.github.io/pharm-island/

三個科目各一頁，導覽列可以切換，進度各自分開存：
- 藥理：`index.html`
- 藥劑：`pharmaceutics.html`（內容在 `js/subjects/pharmaceutics.js`，目前一座島、一章、20 個預留格）
- 藥分：`analysis.html`（內容在 `js/subjects/analysis.js`，目前一座島、一章、20 個預留格）

藥劑、藥分頁是 `index.html` 的複本，只多載入自己的 `js/subjects/*.js`，把章節、單元、知識樹換掉；格式和藥理一樣。改版面時三頁要一起改。

## 答題（`js/quiz.js`）

題目全部從資料裡的挖空 `{{答案|類型}}` 自動產生，不另外寫題庫。
- **挖空題**：一句話挖掉一個答案；錯誤選項從同類型的其他答案抽。藥名題優先抽同一組的藥（最難）；疾病、菌種、副作用等優先抽別章的（同章的藥範圍常重疊，避免一題兩個對）。這個藥資料裡已經寫到的詞、和正確答案太像的詞（IV 和 IV/IM）都不會當錯誤選項。
- **對比組**（`PI.CLOZE_SETS`）：耐酸／不耐酸、可逆／不可逆這類答案，選項只用同組的詞。
- **認藥題**：給這個藥獨有的一兩句特徵（別的藥沒有一模一樣的句子、也沒寫到藥名），問是哪一個藥。
- **挑戰格子**：點「可挑戰」的格子 →「挑戰這格」，連答 3 題，答對 2 題以上佔領（題目不到 3 題時要全對）。已佔領的格子可以「再練習一次」，不影響進度。
- **知識樹**：知識面板上方「開始答題」，每次 5 題，先出還沒答對過的；每題第一次答對 +`PI.LEVEL.expPerTreeQuestion` EXP，存在瀏覽器。
- 答題時資訊卡和知識面板會藏起來；鍵盤 1～4 選答案、Enter 下一題、Esc 關閉。

## 群島地圖

整個世界是一片海，上面有四塊陸地（`js/data.js` 的 `PI.LANDMASSES`）：

- **抗微生物主島**：第 1～8 章共用一座大島，每章是島上的一個區域；地面統一是草地綠。一開始各章分開（只有起點格是陸地），相鄰兩章彼此最靠近的兩格都解鎖後，中間會長出陸橋；全部解鎖完，主島連成一整座島（相鄰關係用最小生成樹決定，保證全部連得起來）。
- **第 9、10、11 章**：各自是獨立的島，地面分別是柔和黃、柔和藍、柔和珊瑚粉，依設定的方向擺放，構圖不對稱。

**配色規則**（`PI.LANDMASSES` 的 `palette`、`PI.MAP.cell`）：
- 同一座島所有已解鎖（可挑戰、已佔領）的格子用同一個底色，就是這座島的地面色；格線統一是淡奶油色。
- 未解鎖的格子透明，只有低調的灰框，看得到海。
- 只有已解鎖的格子底下才是陸地，島會隨著解鎖慢慢長大；主島的各章節區域解鎖到夠近時會連成一片。
- 章節標籤可以用章節識別色，但不影響島的底色。

**地形與格子是分開的兩層**：
- 格子：每章從中心一格往外長（見下方「新增藥物」）。
- 地形：在陸地範圍建立「地形場」（每一格貢獻一點高度＋陸橋＋岬角＋低頻雜訊），再用等高線切出淺水、浪花、沙灘、草地輪廓並平滑。海岸線不是六角格的外緣，格子只是嵌在草地裡。新增格子或格子解鎖時會重新計算地形。

### 每章的大小
- 依該章的學習單元數決定。正式資料還沒進來前，用 `js/data.js` 每章的 `estimate`（預估值）先放「預留格」，不虛構藥名。
- 第 1 章是新手教學島（主題單元）；第 8 章的單元是製劑與分類，不一定是藥品名稱。

### 新增藥物（自動擴展島嶼）
在 `js/units.js` 的 `PI.UNITS` 依序往後加，或在瀏覽器主控台執行：

```js
PI.addUnit({ id: "vancomycin", chapter: 3, name: "Vancomycin", type: "drug", group: "Glycopeptides" })
```

- 先填進該島的預留格；預留格用完後，從島的邊界旁長出新的一格。
- 每次只從「已有格子旁邊的空位」挑位置，所以島一定連通、不重疊、沒有孤立格；挑選時偏好鄰居多、離中心近，再加一點固定亂數，形狀才自然。
- 同一個 `group` 的單元會聚成一團：同組的後續格子會貼著同組、往同組中心靠。
- 只重畫這座島的海岸線；島長到超過預留大小時才重新安排島的位置（只移動，不重畫），島與島之間一定隔著海。
- 已佔領的格子跟著單元 id 走，島移動也不會遺失進度。單元 id 之後不要改。

### 圖層（同一套世界座標）
1. **海水**：`sea-tile.jpg` 平鋪在地圖容器背景，跟著拖曳縮放，拖到哪裡都不會露出空白。
2. **海上裝飾**：小島、礁石、浪花，依區塊（`PI.ART.chunkSize`）需要時才產生，離太遠的區塊會移除。
3. **島嶼地形與海岸線**：每塊陸地一個群組，依地形場的等高線畫出；海岸外的礁石、迷你島跟著陸地走。
4. **六角格**：每章一個群組。
5. **章節標記**：島上方的章節牌，縮小地圖時維持可讀大小。
6. **選取外框**。

只顯示畫面附近的島嶼與裝飾。

### 效能
- 拖曳、縮放時只移動「舞台」（海水＋地圖）的 CSS transform，由 GPU 合成；停下 140ms 後才重新計算 SVG 座標與分區顯示。舞台比畫面大一圈，拖曳時周圍不會露白。
- 三個 HTML 引用 CSS、JS 時帶 `?v=日期` 版本號；改了 CSS 或 JS 要一起改版本號，瀏覽器才不會用舊檔。
- 沒有常駐動畫；每格只有一個六角形，虛線圈、旗子等狀態需要時才加，滑鼠高亮全地圖共用一個元素。
- 地形只在載入、新增格子、重新排列時計算；同一畫面內的多次更新合併成一次。
- 縮得很小時隱藏小花草、礁石、浪花等小裝飾；放大才顯示格子裡的藥名。地圖不受單張圖片尺寸限制，可依資料持續擴展（不是數學上的無限世界）。

## 學習內容與挖空

- 統一模板寫在 `js/units.js` 開頭：每個藥物（或主題）一格，固定欄位為機轉、抗菌範圍、臨床應用、藥動、副作用、禁忌與交互作用、抗藥性、其他重點（`PI.UNIT_FIELDS`），沒有資料的欄位不寫。
- 類別共通的內容（例如 Sulfonamides、Fluoroquinolones 的藥動與副作用）寫在該章知識樹，藥物格用 `class` 指過去，不重複。
- 挖空寫法：`{{答案|類型}}`；句尾 ` #口訣` 是提示。錯誤選項之後從同類型的其他答案自動抽（類型清單 `PI.CLOZE_TYPES`）。
- 藥物格、主題格、知識樹都用同一種寫法，都可以出題。知識樹每答對一題 +`PI.LEVEL.expPerTreeQuestion` EXP，題數與經驗值標在知識面板上方。答題介面尚未製作。

## 知識樹

- 每一章一棵知識樹（抗微生物主島第 1～8 章各一棵，第 9、10、11 章各一棵），長在那一章的初始格子上。
- 樹比格子小，只蓋住格子中央：點樹開知識面板，點格子其他地方照常選格子；這格的旗子會移到右下角。
- 點樹（或用鍵盤選到樹按 Enter）打開知識面板；按 × 或 Esc 關閉，地圖回到打開前的位置。
- 內容寫在 `js/knowledge.js`：每一章一筆（`chapter` 是章節編號），每段的 `items` 照檔案開頭的格式加（`title`、`text`、`points`、`source`）。沒有內容的段落會顯示「尚未加入內容」。沒有列在 `PI.KNOWLEDGE` 的章節不會長樹。
