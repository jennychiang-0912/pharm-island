# PHARMA ISLAND

探索藥理，逐格征服。參考 PaGamO 領土佔領玩法的藥理學複習遊戲（單人模式）。

線上玩：https://jennychiang-0912.github.io/pharm-island/

## 目前進度

- [x] 第一階段：首頁介面（導覽列、左側資訊面板、中央地圖容器、響應式版面）
- [x] 第二階段：資料驅動的六角格地圖（未解鎖／可挑戰／已佔領、拖曳、縮放、點擊）
- [ ] 第三階段：答題與佔領（尚未開始）
- [ ] 第四階段：進度管理（佔領狀態已會存在瀏覽器，等級與經驗值已會跟著領土計算）

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面結構 |
| `css/style.css` | 樣式與配色 |
| `js/data.js` | 分類、11 個章節、地圖與等級設定（只放資料） |
| `js/state.js` | 領土狀態與玩家進度，存在瀏覽器 localStorage |
| `js/map.js` | 六角格產生、繪製、拖曳與縮放 |
| `js/app.js` | 導覽列、側邊面板、格子資訊卡、設定 |

題庫之後會放在 `js/questions.js`，不會寫進地圖格子裡。答題系統只要呼叫 `PI.state.occupy(格子 id)` 就能佔領格子。

## 地圖規則

- 每章一群格子：中心一格加周圍最多六格，數量由 `js/data.js` 的 `cells` 控制（目前每章 7 格）。
- 每章的中心格一開始就是「可挑戰」；佔領一格後，相鄰的格子會變成可挑戰。
